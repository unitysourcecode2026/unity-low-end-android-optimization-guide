# Unity Low-End Android Optimization Guide

A practical collection of Unity optimization techniques, C# examples, and performance guides designed to help developers improve mobile game performance on low-end Android devices.

This repository covers common performance bottlenecks including memory usage, draw calls, garbage collection, object pooling, texture optimization, mobile shaders, frame rate management, and profiling.

## What You'll Learn

- Improve FPS on low-end Android devices
- Reduce memory consumption
- Reduce unnecessary draw calls
- Implement object pooling
- Optimize textures and sprites
- Configure performance settings
- Reduce garbage collection
- Optimize mobile shaders
- Profile Unity games on real devices
